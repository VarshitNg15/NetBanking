# Notification Service

Spring Boot microservice for the NetBanking Notification & Audit domain.

## Package structure

- controller: REST endpoints
- service: business logic
- repository: Spring Data JPA repositories
- entity: Oracle/JPA entities and enums
- dto: request DTOs
- kafka: event consumers and event payloads
- mail: email sender
- exception: API exception handling
- config: Spring configuration
- resources/db/migration: database schema SQL

## Local run

Use the Maven Wrapper generated by Spring Initializr:

- Windows: `mvnw.cmd spring-boot:run`
- Linux/macOS: `./mvnw spring-boot:run`

The Oracle schema must exist before starting the app because `spring.jpa.hibernate.ddl-auto=validate` is enabled.

## Environment variables

- `NOTIFICATION_DB_USERNAME`
- `NOTIFICATION_DB_PASSWORD`
- `KAFKA_BOOTSTRAP_SERVERS`
- `MAIL_USERNAME`
- `MAIL_PASSWORD`

## Initial endpoints

- `GET /health`
- `POST /api/notifications`
- `POST /api/notifications/{id}/send`
- `GET /api/notifications/{id}`
- `GET /api/notifications/customer/{customerId}`
- `POST /api/audit/access/request`
- `POST /api/audit/access/{requestId}/approve`
